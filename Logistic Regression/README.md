# INTRODUCTION 
In this analysis, we will examine the factors influencing car purchases using various statistical 
techniques. By leveraging logistic regression and decision tree analysis, we aim to identify significant 
predictors and evaluate the performance of these models. This comprehensive approach will enable us 
to understand the strengths and limitations of each method in predicting car purchases.
